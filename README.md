## Ukratko
Digitalni vrt je interaktivna generativna ilustracija u kojoj korisnik pomoću miša stvara vlastiti virtualni vrt sastavljen od geometrijskih cvjetova. Svakim klikom miša se stvara novi cvijet na ekranu.

## Kako pokrenuti
1. Instalirajte Thonny i biblioteku py5 (upute kolegija *Radno okruženje*).
2. Otvorite `[digitalni].py` u Thonnyju.
3. Pokrenite tipkom **F5** (ili **Run > Run current script**).

Sve potrebne datoteke nalaze se u mapi `data/`. Rad ne treba internet.
